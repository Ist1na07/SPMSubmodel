# 模型设计与评估

[English](research.md) · [使用说明](../README.zh-CN.md)

## 三个分数共用 SPM 引擎

Submodel 使用 [SPM Rating v1.3.0 修订版 2](https://github.com/Ist1na07/SPMRating/tree/4cbccb5de77e592d201d475041c67aa339ba544a)。它调用上游特征构建和难度计算，包括所选模型的镜像处理、长键释放与协调、连打与技巧的相互作用，以及耐力。上游的逐行聚合准备还负责计算峰值包络，给出每行的难度和参与物量。

三个分数共用上游的对数逻辑斯蒂逐行求解器：找出一个技能值，使各行预测准确率的加权平均达到模型设定的目标。分支继续使用 SPM 的物量修正、高分压缩和标定。原谱计算同时供 SPM 和 LN 使用；RC 另算一次将长键改为头部单点的谱面。纯单点谱可直接复用原谱结果。

## 两个分支如何分配行权重

长键需求来自上游的释放、协调和手指角色项。头部都在同一时刻的持续和弦，也会从上游的支撑行获得难度。先去掉耐力倍率，再比较原谱和头部单点谱；原谱高出的部分会按已有的长键需求折算后加入，避免把纯单点压力算给长键。

用上游释放时间跨度作为三角窗宽，对长键负荷和整场难度分别取局部平均，记为 `L` 和 `D`。局部长键难度份额为 `s = cL / hypot(cL, D)`，空行取零。再结合附近持续长键的头部和被占用的手指数，得到持键支撑 `h`。该行的长键归属度为 `w = s × h`。这些连续权重由谱面计算，谱型标签只用于评估。

- **LN：** 将原谱的行难度乘以 `s`，行权重乘以 `w`。这个分支沿用上游行权重，去掉已经按住的手指带来的物量惩罚。原生求解器得到技能值 `u₀` 后，乘以 `N² / (N² + N₀²)`，其中 `N` 是所有长键头处的 `w` 之和。原生长度修正也用 `N`。最后按 `u / (u + 0.35)` 平滑加入上游的加性偏置，`u` 是暴露折扣后的技能值。有效长键物量趋近零时，原生 LN 分数也趋近零。
- **RC：** 将原谱的所有头部当作单点，取得行难度与权重。用上游耐力时间常数作为三角窗半宽，对 `w²` 求局部平均，记为 `nearby`。每个头部行的权重再乘以 `1 + ((1 − α) / α) × nearby × (1 − h)² × (1 − w²)`。靠近长键段落、且自身持键较少的单点行会获得更多权重。原生求解和长度修正使用总头数。单点段落更难时，RC 可以高于整谱 SPM。

`ln_coverage` 是有效长键头数 `N` 除以总头数，仅作诊断。LN 的暴露公式使用绝对头数 `N`。

固定参数为：局部长键负荷倍率 `c = 16`，达到一半暴露权重所需的有效长键头数 `N₀ = 30`，RC 行权重参数 `α = 0.16`。

小数时间谱面沿用上游的共享相位处理：每个相位分别计算分支分数，再平均原生结果。可选的参考尺度对三个分数应用同一键数的单调分段线性标定。纯单点谱的原生 LN 为零，其参考 LN 是上游标定在零处的取值。

## 评估

下表使用 `detail` 模型和 7K 参考尺度。Spearman 衡量排序的一致程度，平均绝对误差直接比较分数与数值标注。缺失的分支标注和标为 `below_range` 的 LN 标注不参加对应的数值比较。这是开发集结果；新的独立混合谱标注可用来检查它能否推广。

| 7K 比较 | 标注数 | Spearman | 平均绝对误差 |
|---|---:|---:|---:|
| SPM 与综合标注 | 334 | 0.98595 | 0.2295 |
| RC 与 RC 标注 | 200 | 0.98139 | 0.2544 |
| LN 与 LN 标注 | 180 | 0.98298 | 0.2453 |
| 混合谱的 RC 与 RC 标注 | 49 | 0.98478 | 0.3168 |
| 混合谱的 LN 与 LN 标注 | 48 | 0.98152 | 0.2049 |

144 条标为 `below_range` 的记录中，LN 分数的中位数为 0.6557，第 90 百分位为 0.8418，最大值为 6.9984。

146 条 RC 类记录中，RC 与 SPM 的绝对差中位数为 0.000，第 90 百分位为 0.021。130 条 LN 类记录中，LN 与 SPM 的绝对差中位数为 0.077，第 90 百分位为 0.145；同一组中，RC 与头部单点 SPM 的绝对差中位数为 0.012，第 90 百分位为 0.087。

4K、6K 数据集提供综合难度标注。SPM 的 Spearman 相关系数在 4K 的 741 条有效标注上为 0.98550，在 6K 的 2,343 张有效谱面上为 0.95926。4K 的 102 条 LN 类记录中，LN 分数与综合标注的 Spearman 相关系数为 0.98085，平均绝对误差为 0.7034。`bm6k_1460` 在同一键同一时刻有多个尾部不同的物件，按上游规则拒评。

分支检查另用段位谱：先分别拟合 RC 和 LN 梯子的分数与段位，再比较共有段位处的拟合值。平均绝对差在 4K 的 1–15 段为 **0.2363 dan**，在 6K 的 0–9 段为 **0.6165 lv**。两者使用各自的参考尺度。4K REFORM 的 alpha 到 epsilon 对应 11–15 段。7K 直接使用数据集转换后的数值标注；gamma、azimuth、zenith、stellium 对应 11–14 段。

可用[使用说明](../README.zh-CN.md#复现评估)中的命令生成逐谱结果、排序指标与段位拟合。自动测试覆盖各键数和模型的 SPM 一致性、纯单点谱、镜像、变速、小数时间、持续和弦及参考尺度标定。
