# 模型设计与评估

[English](research.md) · [使用说明](../README.zh-CN.md)

## 三个分数共用 SPM 引擎

Submodel 使用 [SPM Rating v1.3.0 修订版 2](https://github.com/Ist1na07/SPMRating/tree/4cbccb5de77e592d201d475041c67aa339ba544a)。它调用上游特征构建和难度计算，包括所选模型的镜像处理、长键释放与协调、连打与技巧的相互作用，以及耐力。上游的逐行聚合准备还负责计算峰值包络，给出每行的难度和参与物量。

三个分数共用上游的对数逻辑斯蒂逐行求解器：找出一个技能值，使各行预测准确率的加权平均达到模型设定的目标。分支继续使用 SPM 的物量修正、高分压缩和标定。原谱计算同时供 SPM 和 LN 使用；RC 另算一次将长键改为头部单点的谱面。纯单点谱可直接复用原谱结果。

## 两个分支如何分配行权重

长键在场程度 `g` 以当前行为中心，取 700 毫秒窗口。把每条长键的起点提前 75 毫秒、终点延后 75 毫秒，以纳入附近的按下和释放动作；合并重叠区间后，取覆盖时间比例的平方根。多个长键同时按住时，重叠的时间只算一次；没有长键覆盖的空白时间不会计入。信号在上游行网格上计算，也适用于 SPM 为持续和弦增加的支撑行。

- **LN：** 将原谱行权重乘以 `g`，再求解同一个准确率方程。保留的物量比例 `c` 作为 `ln_coverage` 输出。物量修正使用 `头部数量 × c`，之后将原生 LN 分数乘以 `c / (c + 0.15 × (1 − c))`。长键内容很少时分数平滑趋近零；覆盖接近全谱时，计算趋近原生 SPM。
- **RC：** 使用头部单点谱的难度与行权重。对每个头部行，取原谱局部难度乘以 `g`，再除以头部单点局部难度（分母设很小的数值下限）。比例为 `r` 时，将 RC 行权重乘以 `0.10 + 0.90 / (1 + 4r²)`。局部长键需求越强，该行在 RC 中相对越轻，但仍保留一部分权重。整谱求解使用原头部数量。

所有谱面使用相同的公式。评分过程不读取谱型标签，不使用分类器，也不根据整谱难度比例打开或关闭 RC 调制。键数由谱面解析得到，用于上游的列布局和标定。谱型标注只用于离线统计。

小数时间谱面沿用上游的共享相位处理：每个相位分别计算分支分数，再平均原生结果。可选的参考尺度对三个分数应用同一键数的单调分段线性标定。纯单点谱的原生 LN 为零，其参考 LN 是上游标定在零处的取值。

## 评估

下表使用 `detail` 模型和 7K 参考尺度。Spearman 衡量排序的一致程度，平均绝对误差直接比较分数与数值标注。缺失的分支标注和标为 `below_range` 的 LN 标注不参加对应的数值比较。这是开发集结果；新的独立混合谱标注可用来检查它能否推广。

| 7K 比较 | 标注数 | Spearman | 平均绝对误差 |
|---|---:|---:|---:|
| SPM 与综合标注 | 334 | 0.98595 | 0.2295 |
| RC 与 RC 标注 | 200 | 0.98423 | 0.2313 |
| LN 与 LN 标注 | 180 | 0.98140 | 0.2844 |
| 混合谱的 RC 与 RC 标注 | 49 | 0.98375 | 0.2235 |

146 条 RC 类记录中，RC 与 SPM 的绝对差中位数为 0.000，第 90 百分位为 0.016。130 条 LN 类记录中，LN 与 SPM 的绝对差分别为 0.007 和 0.047；同一组中，RC 与独立计算的头部单点 SPM 的绝对差分别为 0.063 和 0.201。

4K、6K 数据集提供综合难度标注。SPM 的 Spearman 在 4K 的 741 条有效标注上为 0.98550，在 6K 的 2,343 张有效谱面上为 0.95926。6K 的 `bm6k_1460` 在同一键同一时刻的多个物件有不同尾部，按上游规则无法评分。

分支检查另用段位谱：先分别拟合 RC 和 LN 梯子的分数与段位，再比较共有段位处的拟合值。平均绝对差在 4K 的 1–15 段为 **0.242 dan**，在 6K 的 0–9 段为 **0.507 lv**。两者使用各自的参考尺度。4K REFORM 的 alpha 到 epsilon 对应 11–15 段。7K 直接使用数据集转换后的数值标注；gamma、azimuth、zenith、stellium 对应 11–14 段。

可用[使用说明](../README.zh-CN.md#复现评估)中的命令生成逐谱结果、排序指标与段位拟合。自动测试覆盖各键数和模型的 SPM 一致性、纯单点谱、镜像、变速、小数时间、持续和弦及参考尺度标定。
