# 研究与验证报告

[English](research.md) · [使用说明](../README.zh-CN.md)

## 算法设计

基线为 SPM Rating 1.2.0-rc3，提交 `a914a405d8e9a77f94c0518567c37511b0b7ac05`，使用 `detail` 参数。旧子模型基于 SPM 1.0.0：RC 计算头部单点谱面的难度，LN 对原谱难度曲线重新加权。旧版依赖单层幂平均聚合，并假设若干曲线不受长键影响。

新版分别计算原谱与镜像谱，共享两者的平均释放曲线，并在各视角合并手部共同接触成本和长时间占用手指后的动作成本。新版还使用连续的恢复与跨列转换曲线、两层段落与窗口聚合，以及小数时间的共享相位扩展。这些内容均保留在综合难度和两个分支中。SPM 的 detail 模型保留了有条件的长键时长项，compact 模型关闭了这一项。实现为头部单点谱构建单独的结构并重算受长键影响的数值曲线，同时共享解析后的音符、基于头部的手部接触与恢复计算，以及 LN 分支所用的原谱难度曲线。无长键谱面直接复用综合难度作为 RC 难度。这样无需运行第三次完整模型，同时保留独立头部单点谱的定义。

### RC 难度

将每个长键替换为同一时间、同一实体列上的头部单点，再以相同 SPM 模型和尺度评分。因此纯单点谱的 RC 难度等于 SPM 难度。转换前会按上游规则验证原谱，包括重复物件和冲突物件。

### LN 难度

1. 标记有长键键体、长键头部，或位于长键尾部时间之后的下一行。头部和尾部使用逐物件数据。若尾部晚于最后一行，则没有下一行可标记。
2. 用 SPM 的 700 毫秒居中窗口平滑在场信号并取平方根，得到 0 到 1 之间的逐行权重 `g`。
3. 在 SPM 两层聚合中，将逐行参与物量乘以 `g`，保留原有的段落与窗口划分、幂平均、难度曲线及按住降权。覆盖率 `c` 为加权物量之和除以原物量之和。
4. 用 `头部数量 × c` 作为有效物量执行 SPM 后处理，再将原生 LN 分数乘以 `min(c / 0.40, 1)`。需要参考尺度时，最后应用上游标定。

全场长键覆盖时，加权和有效物量接近 SPM 的计算；没有长键时，覆盖率与 LN 难度均为零。混合区域中的普通按键难度与长键协调、释放和手指占用成本共同参与计算。覆盖率折减反映长键内容在全谱中的占比；较难的长键段占比足够大时仍可能得到较高分数。

小数时间谱面的每个共享取整相位分别执行上述计算，原生分数加权平均后再做参考尺度标定。返回的覆盖率是各相位覆盖率的加权平均，仅用这个平均值代入公式不一定能复现 LN 分数。

## 参数选择

在场窗口和平方根平滑沿用旧子模型。在所给 7K 开发标注上，比较了覆盖率阈值 0.05、0.10、0.15、0.20、0.30、0.40，以及折减指数 0.5 和 1。采用阈值 0.40 的线性折减后，`below_range` 组分数的第 90 百分位从 6.95 降至 0.48；有效 LN 的 Spearman 从 0.98467 变为 0.98515，平均绝对误差从 0.2701 变为 0.2664，数值使用参考尺度。运行 `python evaluation/calibrate.py` 可利用保存的整数时间结果复现候选参数比较。该阈值是此数据上的实用选择，仍需更多谱面验证。4K 和 6K 段位谱提供额外对齐检查，但不包含完整的分键型标注。两个分支没有拟合额外的逐键数尺度系数。

## 验证结果

下表使用 `detail` 模型和上游 `reference` 尺度。Spearman 等级相关衡量排序；平均绝对误差直接比较对应参考尺度的分数和标注，没有额外拟合回归。`below_range` 标注不参加有效 LN 数值指标，缺失分支标注也不按零处理。7K 中一张谱面的两条标注各保留一条记录。所给标注和谱面在开发期间均可查看，因此这些结果属于样本内评估。

保存结果最初按没有最终覆盖率折减的版本计算，随后利用保存的覆盖率和上游标定转换为选定折减的 LN 分数。所给谱面的原始时间均为整数毫秒，因此这种转换与评分时应用折减的结果仅有浮点舍入差异；已抽样与重新评分结果核对。

| 7K 比较 | 标注数 | Spearman | 直接平均绝对误差 |
|---|---:|---:|---:|
| SPM 与 overall | 334 | 0.98989 | 0.2303 |
| RC 与 RC | 200 | 0.98305 | 0.2698 |
| SPM 与 RC，对照 | 200 | 0.98004 | 0.3239 |
| LN 与有效 LN | 180 | 0.98515 | 0.2664 |
| SPM 与有效 LN，对照 | 180 | 0.98789 | 0.2424 |

146 条 RC 类型标注中，`abs(RC − SPM)` 的中位数和第 90 百分位分别为 0.0000、0.0217；130 条 LN 类型标注中，`abs(LN − SPM)` 分别为 0.0035、0.0694。144 条 `below_range` 记录的 LN 分数中位数为 0，第 90 百分位为 0.475，最大值为 8.105。例如 `bm_0204` 的覆盖率为 0.373、LN 分数为 8.105，但标注为 `below_range`；它可用于研究短长键段与标注语义之间的差异。

4K 的 SPM 与综合标注相关为 0.98833，共 741 条有效标注。RC 分支与综合标注在 jack、speed、stamina、tech 子集上的相关分别为 0.98605、0.98859、0.98349、0.99026；LN 分支在 LN 子集上的相关为 0.98477。由于 4K 缺少完整分支标注，这些结果用于子集检查。

6K 中，SPM 与综合标注在 2,343 条成功评分的记录上相关为 0.95722。另有 `bm6k_1460` 在同一实体键上存在同时发生的冲突物件，上游输入规则拒绝该谱面；失败信息保留在结果文件中。

段位谱比较在各自键数的参考尺度上进行。分别对分数与段位做线性拟合，再比较两条梯子共有整数段位处的拟合值；同段位的多张谱面保留为独立观测。LN 与 RC 拟合值的平均绝对差，4K 1–15 段为 0.247，6K 0–9 段为 0.672。拟合差值在 4K 从 +0.561 变化到 −0.284，在 6K 从 +1.147 变化到 −1.271。段位梯子是近似锚点，两条梯子的斜率差异仍然存在。可用 `evaluation/report.py` 重现各段位结果与拟合。

4K REFORM 的 alpha 至 epsilon 按 11–15 段识别。7K 的 gamma、azimuth、zenith、stellium 对应 11–14 段。7K 分支评估直接使用 `labels.json` 中已有的 `sr` 数值；数据集元数据另行记录了生成这些数值所用的转换。段位名称编号不会直接替换这些数值标注。

## 验证与后续研究

自动测试在 4K、6K、7K，两个上游模型，单点、混合与长键谱型以及变速条件下，将 SPM 与 RC 输出同独立上游调用比较；测试还覆盖镜像、小数时间相位、尺度转换、取消与无效输入。预热后对 30 张选取的 7K 谱面计时，本实现耗时 3.016 秒；分别对已解析的原谱和头部单点谱调用上游耗时 3.351 秒。该小样本不含解析，结果受硬件和谱面影响。LN 使用已经算出的原谱难度曲线。

LN 阈值与沿用的平滑参数需要在新的独立标注混合谱上验证。4K 与 6K 的完整 RC/LN 标注有助于评估跨键数迁移。大量相位断点的小数时间谱、无头部长键区间和分段评分还需要专门的性能或接口研究。compact 模型已检查分支一致性，其分支校准和数据集表现仍待研究。评估脚本可在本地 `results/` 生成逐谱结果和失败记录。
