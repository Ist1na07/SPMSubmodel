# 模型设计与评估

[English](research.md) · [使用说明](../README.zh-CN.md)

## 使用的组件

模型使用 SPM Rating 1.2.0-rc3，提交 `a914a405d8e9a77f94c0518567c37511b0b7ac05`。解析器将 4K 和 6K 谱面映射到七列框架；评分器分别计算原谱与镜像谱，合并释放需求，并计入手部共同接触和手指占用成本。恢复、跨列转换、两层段落与窗口聚合，以及小数时间的共享相位扩展均来自 SPM Rating。默认的 `detail` 模型保留了有条件的长键时长项，`compact` 模型关闭了这一项。

SPM、RC、LN 共用解析、基于头部的手部接触与恢复计算，以及原谱难度曲线。RC 还会将每个长键替换为头部单点，计算对应的难度曲线。纯单点谱直接复用 SPM 分数作为 RC 分数。输入验证遵循上游对实体物件的规则。

## LN 难度

逐行在场信号标记长键键体、长键头部，以及长键尾部时间之后的第一行。尾部晚于最后一行时没有下一行可标记。信号经过 700 毫秒居中窗口平滑并取平方根，得到 0 到 1 之间的权重 `g`。

SPM 原有的两层聚合将逐行参与物量乘以 `g`，保留段落与窗口划分以及难度曲线。覆盖率 `c` 为加权物量与原物量之比。SPM 后处理使用 `头部数量 × c` 作为有效物量，再将原生 LN 分数乘以 `min(c / 0.40, 1)`。使用参考尺度时，最后应用上游逐键数标定。没有长键的谱面 LN 难度为零。LN 难度计入长键区域中的普通按键需求，以及释放、协调和手指占用需求。

## RC 难度

头部单点难度曲线使用 SPM 相同的两层窗口聚合。各窗口对整谱的贡献通过**局部 LN 和 RC 难度估计值**调整，两者都使用原生难度曲线的单位：

1. 局部 RC 难度是头部单点曲线在窗口内以参与物量加权的幂平均。
2. 局部 LN 难度使用原谱曲线，将参与物量乘以 `g` 后求幂平均。窗口 LN 覆盖率使用同一参与物量计算，并提供 `min(窗口覆盖率 / 0.40, 1)` 的内容占比系数。这样既保留 LN 分支对长键区域的关注，也让两项局部估计处于可比较的单位。
3. 局部比例为 `q = clamp(局部LN / max(局部RC, 1e-9), 0, 1)`。
4. 整谱比例为 `r = LN分数 / max(头部单点分数, 1e-9)`，使用参考尺度标定之前的原生后处理分数。调制强度为 `0.90 × clamp((1.60 − r) / 0.40, 0, 1)`。
5. 窗口 RC 参与物量乘以 `1 − 强度 × q`，然后按 SPM 的第二层幂平均和后处理计算整谱分数。

窗口权重最少保留原物量的 10%。局部 LN 相对 RC 越难，窗口对 RC 分数的贡献越低；整谱 LN 难度明显占主导时，调制逐渐减弱。最终 RC 分数可能上升或下降，取决于各区域的难度分布。三个输出使用同一选定的 `raw` 或 `reference` 尺度；参考尺度的标定按键数分别进行。

小数原始时间谱面在每个共享取整相位分别计算难度曲线、局部比例和分支分数，再将原生分数按相位加权平均，最后应用参考尺度标定。覆盖率也按相位平均。

## 参数选择

7K 开发集提供了用于选择 RC 参数的完整分键型标注。参数网格比较了强度 0.75、0.90、0.97，以及整谱比例上限 1.40、1.60、1.80、2.00，渐退区间固定为 0.40。选用强度 0.90、上限 1.60，兼顾混合谱标注拟合和 LN 难度占主导时的平滑渐退。可运行 `python evaluation/experiment_rc.py` 在所给整数时间谱面上复现网格。窗口和整谱的 LN 内容占比阈值均为 0.40。

这些参数根据现有数据选择。新的独立标注混合谱以及 4K、6K 的完整分键型标注，可用于检查不同谱面与键数之间的适用性。compact 模型已通过一致性测试；下方数值评估使用 detailed 模型。

## 评估

分数使用对应键数的上游 `reference` 尺度。Spearman 等级相关衡量排序；平均绝对误差直接比较分数和标注，不额外拟合回归。缺失的分支标注不参与计算，标为 `below_range` 的 LN 记录不参加有效 LN 数值比较。7K 数据集包含 332 张谱面、334 条标注，其中两张谱面各有两条标注。开发期间可以查看这些数据，因此结果属于样本内评估。

| 7K 比较 | 记录数 | Spearman | 直接平均绝对误差 |
|---|---:|---:|---:|
| SPM 与综合标注 | 334 | 0.98989 | 0.2303 |
| RC 与 RC 标注 | 200 | 0.98436 | 0.2561 |
| LN 与有效 LN 标注 | 180 | 0.98515 | 0.2664 |
| HB 谱面的 RC 与 RC 标注 | 49 | 0.98329 | 0.3171 |

HB 组 RC 的平均有符号误差为 −0.1512。144 条 LN 标注为 `below_range` 的记录中，LN 分数中位数为 0，第 90 百分位为 0.475，最大值为 8.105。`bm_0204` 的 LN 分数较高而标注为 `below_range`，可用于研究局部长键段与标注之间的关系。

4K 和 6K 的现有标注为综合难度，不能直接验证各分支。4K 的 741 条有效标注中，SPM 与综合标注的 Spearman 为 0.98833。RC 与综合标注在 jack、speed、stamina、tech 子集上的相关分别为 0.98615、0.98738、0.98221、0.99070；LN 与综合标注在 LN 子集上的相关为 0.98477。6K 的 2,343 条成功评分记录中，SPM 与综合标注的 Spearman 为 0.95722。另有 `bm6k_1460` 在同一实体键上存在同时发生的冲突物件，被上游输入规则拒绝。

段位检查分别对 RC 和 LN 梯子的分数与段位做线性拟合，再比较两条梯子共有整数段位处的拟合值。平均绝对差在 4K 1–15 段为 0.235，在 6K 0–9 段为 0.672；两个数值各自使用对应键数的参考尺度。4K REFORM 的 alpha 至 epsilon 按 11–15 段识别。7K 的 gamma、azimuth、zenith、stellium 对应 11–14 段；数值 `sr` 标注按数据集提供的结果使用，并保留其数据集转换。

## 检查与后续研究

测试覆盖与上游独立计算的 SPM 一致性、纯单点谱、镜像、变速、小数时间、尺度转换和无效输入。受控测试在固定长键在场模式和 RC 曲线的情况下改变 LN 难度曲线，检查 RC 权重的响应。可用 `evaluation/run.py` 在本地生成逐谱结果和失败记录，并用 `evaluation/report.py` 汇总。

后续可收集新的混合谱分键型标注，对比长键物量相近但协调难度不同的谱面，并验证分段难度。不同小数时间很多的谱面可能需要多次共享相位计算；当前整谱接口不提供无头部长键区间与分段评分。
